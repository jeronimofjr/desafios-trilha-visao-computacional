## Desafios de Visão Computacional: Detecção, Rastreamento e Reconhecimento de imagens

É um repositório com desafios de visão  computacional propostos pela trilha de visão computacional ofertada pelo Instituto Eldorado em parceria com a Softex.

### Desafios

* **Desafio 01**: Detecção facial utilizando classificadores `Haar cascade` e `redes neurais profundas`.
* **Desafio 02**: Reconhecimento facial com modelos de redes neurais pré-treinados.
* **Desafio 03**: Rastreamento de objetos em vídeo com `YOLO`.
* **Desafio 04**: Reconhecimento de poses para análises esportivas.

## Tecnologias Utilizadas

* **OpenCV** para tarefas de visão computacional
* **Caffe** para deep learning
* **Torch** para deep learning
* **Python** para scripting e desenvolvimento
* **Jupyter** Notebooks para desenvolvimento e testes interativos
